# Adrobot · Keitaro

Веб-интерфейс для создания кампаний и редактирования офферов в существующих потоках Keitaro. FastAPI вызывает Admin API, SQLAlchemy хранит черновики в SQLite, а Alembic управляет схемой базы.

## Запуск

Нужны Python 3.12+ и действующий ключ Keitaro Admin API с доступом к кампаниям, потокам, справочникам и отчётам. Выполняйте команды из корня репозитория.

```sh
python -m venv .venv
```

Активируйте окружение. В PowerShell выполните `.\.venv\Scripts\Activate.ps1`, на macOS и Linux — `source .venv/bin/activate`.

```sh
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Укажите `KEITARO_URL` в формате `https://tracker.example` и заполните `KEITARO_API_KEY`. Ключ используется на сервере и хранится локально. `DATABASE_URL` по умолчанию создаёт файл `adrobot.db` в корне проекта. [Документация Keitaro Admin API](https://docs.keitaro.io/en/development/admin-api.html)

```sh
python -m alembic upgrade head
python -m uvicorn app.main:app
```

Откройте [интерфейс](http://127.0.0.1:8000/) или [OpenAPI](http://127.0.0.1:8000/docs). Запускайте локально с одним процессом Uvicorn. Приложение использует один настроенный ключ и не включает многопользовательскую авторизацию.

## Что проверить

1. Введите название, двухбуквенный код страны, выберите оффер, домен, группу и источник. Приложение создаст кампанию с упорядоченными потоками. Первый принимает трафик из указанной страны и перенаправляет его на Google. Второй служит потоком по умолчанию и отправляет остальной трафик на оффер.
2. Откройте кампанию из списка или по ID и выберите поток с офферами. Добавьте оффер из списка или введите его ID. Удаление, добавление и закрепление долей сохраняются в черновике SQLite.
3. Нажмите **Отправить в Keitaro**, чтобы применить черновик, либо **Сбросить черновик**, чтобы загрузить актуальные офферы из трекера. Если офферы в Keitaro изменились после начала редактирования, интерфейс покажет конфликт.

Для активных офферов сумма долей равна 100%, если в потоке есть активные офферы. Закреплённые проценты сохраняются. Остаток делится поровну, а лишние процентные пункты распределяются сверху вниз. У трёх свободных офферов получатся 34%, 33% и 33%. Клики и конверсии за последние 7 дней загружаются из отчёта Keitaro по выбранному потоку и часовому поясу Europe/Moscow.

Кампания создаётся выключенной и активируется после создания обоих потоков. Если создание прервётся после получения ID кампании, приложение покажет этот ID для проверки в Keitaro.
